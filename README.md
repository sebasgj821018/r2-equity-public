# equity-football-risk

Toolkit open-source para cuantificar la **inequidad logistica estructural** de ligas
continentales de futbol como un **riesgo transferible**: primas actuariales, TVaR,
transferencias solidarias y CoVaR empirico.

> Este repositorio contiene **unicamente datos sinteticos**. Es la contraparte publica
> de una investigacion en curso (WCSF 2027); no se distribuyen datos reales ni resultados.

## Instalacion
```bash
pip install -e .
```

## Quickstart
```bash
python examples/quickstart.py
```

## Tests
```bash
python -m pytest tests/
```

## Modulos
`inequality` | `actuarial` | `covar_log` (ver `docs/API.md`)
