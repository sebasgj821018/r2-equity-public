# API — equity-football-risk v0.1.0

- `inequality.gini(x)` / `inequality.theil_t(x)`: desigualdad de carga.
- `actuarial.pure_premium(L)`: prima pura E[L].
- `actuarial.tvar(L, q=0.95)`: Expected Shortfall.
- `actuarial.solidarity_transfers(P)`: T_i = P_i - P_barra.
- `covar_log.delta_covar_empirico(X, E, q=0.95)`: delta-CoVaR empirico (demo).

Datos incluidos: SOLO sinteticos (`data_synthetic/`).
